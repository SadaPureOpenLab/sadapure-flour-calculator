# SEO and custom-order contact

Updated 14 October 2026 for https://sadapureopenlab.github.io/sadapure-flour-calculator/ .

- Descriptive English title/H1 with international **Flour (Atta)** wording.
- Specific meta description, index/follow directive and canonical base URL. Share-query versions canonicalize to the main calculator.
- Open Graph and Twitter metadata using the authentic emblem.
- WebApplication JSON-LD with a truthful publisher and free browser access. No invented ratings, endorsements, clinical credentials or human authorship claims.
- Readable initial HTML and JavaScript-disabled help; the rendered app replaces the same introductory content.
- One-URL sitemap at the project path. No fictional language routes or private share URLs are submitted as sitemap entries. A project-path robots.txt would not govern the domain, so it is not claimed as domain crawler configuration.
- Relevant product and business-contact links with clear anchor text.

References checked: [Google SEO starter guide](https://developers.google.com/search/docs/fundamentals/seo-starter-guide), [canonical guidance](https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls).

Search Console ownership is verified and the homepage indexing request was accepted into the priority crawl queue. Sitemap submission was accepted; the report initially showed Couldn't fetch, while a subsequent Google live URL test confirmed the sitemap fetch Successful and crawling allowed. It was resubmitted once. Actual indexing and ranking remain unconfirmed. There is no guarantee that an external detector will classify content a particular way. The interface has no AI branding and does not falsely label its recipe examples as human- or dietitian-approved.

## Product/contact provenance

Product button: https://sadapure.com/product/multi-grain-atta-flour . This is the same public page used for the original ingredient snapshot.

Order email: contact@sadapure.com, verified in the official website footer. A mailto draft includes only ingredient names, percentages, gram weights and batch quantity. Health-goal names, diagnosis, personal context and source URLs containing condition names are omitted. The visitor chooses whether to send; no email was sent by the agent during implementation or verification.

For long 54-entry shared mixtures, the draft stays below 1,900 URI characters and asks the visitor to attach the CSV. The request does not commit to a price, delivery, manufacturing availability or confirmed order.
