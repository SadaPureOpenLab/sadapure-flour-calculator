# Security and privacy

Do not publish vulnerabilities, credentials, customer information or private health data in public issues. Send a concise report to contact@sadapure.com with the project name, affected version, reproducible steps and impact. Do not access unrelated accounts or data while investigating.

Open Lab's initial calculators process inputs locally and need no accounts, analytics or clinical AI service. Shared results must contain only public ingredient ratios and quantities. Evidence-based ingredient/allergen corrections are welcome, but an absence of listed allergens is not a cross-contact guarantee.

No response-time promise or external security audit is claimed.
