# Contributing to SadaPure Open Lab

Start with a concrete problem: an incorrect weight, unclear source, missing label, keyboard obstacle or ingredient translation. State the relevant project, steps and expected result. Do not post customer details, orders, diagnoses, medical records or credentials.

For formula changes, supply a public source, retrieval date and exact change. Published formulas remain immutable snapshots; a new verified version is a separate data update. Clinical benefit, nutrition values, gluten-free status and batch records need evidence beyond ingredient arithmetic.

Keep contributions small. Add calculation tests for changed arithmetic and check the relevant mobile/keyboard flow. Show original work or document the license of any reused code and assets. Brand assets remain outside the software license.

Researchers and Urdu translators are welcome. Identify ambiguity rather than guessing species, nutrient values or product claims. Product questions belong with [SadaPure support](https://sadapure.com/contact-us).
